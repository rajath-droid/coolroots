# CoolRoots — Ancient Wisdom. Modern Cooling.

A full-featured e-commerce storefront prototype for traditional Indian passive-cooling and heat-reduction solutions, built with React, TypeScript, Vite, Tailwind CSS, and React Router.

## Features
- **Storefront & Catalog**: 7 product categories (Terracotta Cooling Towers, Khus Grass Screens, Matka Cooling Systems, Lime-Washed Roof Kits, Jali Architecture Panels, Courtyard Cooling Design Consultations, and Bamboo & Chick Blinds) plus 3 curated Cooling Bundles.
- **Product Details**: Live variant/size pricing, material options, specifications, climate suitability, and honest cooling limitations.
- **Persistent Cart & Demo Checkout**: Full cart management and simulated checkout persisted in `localStorage`.
- **Find Your Cooling Solution**: Rule-based interactive recommendation matcher requiring zero external APIs.
- **Cooling Guide, About & Contact**: Educational comparison of passive cooling vs. AC, startup mission, and interactive demo inquiry form + FAQ.
- **Seller / Admin Dashboard (`/admin`)**: Unauthenticated demo dashboard for editing prices, descriptions, coverage areas, stock, variants, bundles, adding/deleting products, and updating demo order statuses.

## Running Locally
```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.
